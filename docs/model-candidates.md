# 판단 보조 산출물 정의

> 2026-09-17 개정. `investment-support-plan.md` 개정에 맞춰 다시 썼다. 초안에서 뺀 것과 이유는 §8에 있다.
> 이름을 "모델 후보"에서 "산출물 후보"로 바꿨다. 1차에 남은 것 중 학습하는 모델은 없다. 전부 이미 있는 값의 집계와 문턱 판정이다.

## 1. 공통 원칙

- 산출물은 투자 추천이 아니라 판단 보조 정보다.
- 현재 시점까지 관측된 값만 쓴다.
- 검증은 "미래 수익률 적중"이 아니라 안정성, 설명 가능성, 수동 검토 일치, 누수 방지로 본다.
- 동별 상대 수익률 예측에 실패한 feature를 이름만 바꿔 다시 쓰지 않는다. 이름을 바꾸면 실패한 신호가 라벨로 되살아난다.
- **과거 변화율에 이름(라벨)을 붙이지 않는다.** 라벨은 그 상태가 이어진다는 뜻으로 읽히는데, 결정 51·55·57·58이 그 뜻을 부정했다.
- **변화율은 측정오차와 함께만 낸다.** 오차보다 작은 차이는 수치로 내지 않는다.
- 새 문턱을 만들지 않는다. 이미 결정에 있는 문턱(매매 20건, 단지 비중 50%, SE 구간)을 재사용한다.

## 2. 후보 요약

| 순위 | 산출물 | 방법 | 출력 | 단계 |
|---|---|---|---|---|
| 1 | 표본 주의 flag | 기존 문턱 3개 판정 | `sample_flags` | 1차 |
| 2 | 12개월 변화 표시 | δ와 SE 비교, 구분 가능할 때만 수치 | `change_12m`, `delta_state` | 1차 |
| 3 | 구조 유형 | K-S 클러스터 소속 + 프로필 자동 설명 | `structure_type`, `structure_desc` | 1차 |
| 4 | 함께 볼 동 | 같은 클러스터 안 최근접 5개 | `peer_dongs` | 1차 |
| 5 | 이벤트 전후 경로 | `event_dong_path` 경로 + 오차 띠 | 그래프 데이터 | 2차 |
| 6 | leave-one-complex-out 변화율 | 상위 단지 제외 재추정 | `delta_excl_top` | 2차 |

전세 구조 점수와 이벤트 민감도 프로필은 산출물에서 뺐다. 이유는 §8-4, §8-5.

## 3. 표본 주의 flag

### 목적

동별 변화율을 얼마나 조심해서 읽어야 하는지 알린다. 등급을 매기지 않는다.

### 입력

| 값 | 출처 |
|---|---|
| `sale_n_all_4q` | `dong_feature` |
| `n_complexes_4q` | `output/62.1.dong_complex_concentration.txt` |
| `dominant_complex_share_4q` | 같음 |
| `log_index_se` | `dong_index` (결정 42 정의) |

### 판정

| flag | 조건 | 문턱 근거 |
|---|---|---|
| `FEW_SALES` | `sale_n_all_4q` < 20 | 결정 7의 eligible 기준과 같은 값 |
| `ONE_COMPLEX_DOMINATES` | `dominant_complex_share_4q` > 0.5 | `models/index/62`가 이미 이 비율로 분포를 보고한다 |
| `HIGH_INDEX_ERROR` | `log_index_se`가 eligible 동 분포 상위 구간 | 결정 42. eligible 중앙값 0.0176, 비eligible 0.0585 |

`n_complexes_4q`는 flag를 만들지 않고 화면에 수치로만 낸다. 거래 단지 수가 적다는 사실은 위 두 flag가 대부분 같이 잡는다.

### 출력

```json
{
  "sample_flags": ["ONE_COMPLEX_DOMINATES"],
  "sale_n_all_4q": 31,
  "n_complexes_4q": 3,
  "dominant_complex_share_4q": 0.58,
  "index_se": 0.0243
}
```

flag 이름은 payload에만 쓴다. 화면 문장은 `wording-guide.md`가 정한다.

### 검증

- `log_index_se`가 큰 동이 flag 없이 통과하지 않는지 단조성 확인
- 매매 20건 경계 근처 동을 수동 20개 뽑아 flag와 실제 거래 내역이 맞는지 점검
- flag가 붙는 동의 비율을 기점별로 보고 특정 분기에 몰리지 않는지 확인

## 4. 12개월 변화 표시

### 목적

동 변화율과 서울 평균의 차이를 측정오차와 함께 낸다. 예측이 아니라 지난 12개월 관측값이다.

### 계산

| 값 | 정의 |
|---|---|
| 동 변화 | `log_index[T] − log_index[T−4]` |
| μ(서울 공통) | 재고(세대수)가중 동 지수의 같은 기간 변화 (결정 43) |
| δ | 동 변화 − μ |
| δ 오차 | √(`se[T]`² + `se[T−4]`²). 두 시점 SE가 같으면 √2 × SE다(결정 42). 산식은 `process.md` §2.1 F-2 |
| 5년 최고 대비 | `log_index[T]` − max(`log_index[T−19..T]`). 오차는 T와 최고 분기 SE의 제곱합 제곱근 |

5년 최고 대비는 투자자가 실제로 확인하는 값이라 넣는다(`investment-support-plan.md` §2.1). 주의: 잡음이 큰 계열의 최댓값은 위로 치우친다. 저거래 동은 최고점이 실제보다 높게 잡혀 "최고 대비 −x%"가 과장된다. `FEW_SALES`나 `HIGH_INDEX_ERROR` 동은 이 값을 내지 않거나 오차를 함께 크게 보여 준다. 어느 쪽인지는 `feature-spec.md`에서 정한다.

### 표시 규칙

| 조건 | `delta_state` | 화면 |
|---|---|---|
| \|δ\| > 2 × δ 오차 | `DISTINGUISHABLE` | δ 수치와 오차 병기 |
| 그 외 | `INDISTINGUISHABLE` | "서울 평균과 구분되지 않음", δ 수치 없음 |

2σ 기준은 임의 선택이다. `feature-spec.md`에서 이 문턱으로 몇 개 동이 `DISTINGUISHABLE`이 되는지 세고, 거의 전부 또는 거의 0이면 다시 정한다.

### 검증

- 저거래 동이 `DISTINGUISHABLE`로 넘어가는 비율이 eligible 동보다 낮은지 확인 (높으면 SE 정의가 잘못된 것)
- 인접 분기 사이 `delta_state`가 뒤집히는 비율 확인
- δ 값의 부호가 연속 분기에서 무작위로 바뀌는지 확인. 그렇다면 오차 문턱이 너무 낮다

## 5. 구조 유형

### 목적

동을 같은 기준으로 묶어 비교 대상을 좁힌다. 예측이 아니라 관측 특성 군집이다.

### 입력

`models/index/66.build_dong_cluster.py`의 K-S(구조 변수) 산출물을 그대로 쓴다. 새로 만들지 않는다.

| 산출물 | 내용 |
|---|---|
| `output/66.1.dong_cluster.txt` | 기점별 동 소속 (`as_of`, `dong`, `cluster`) |
| `output/66.3.cluster_profile.txt` | 클러스터별 평당가 중앙, 전세가율, 신축비중, 도심거리, 강남거리 |

K=4는 성능이 아니라 인접 기점 간 ARI로 고정했다(중앙값 0.903, 결정 57). 구 소속과의 ARI는 0.110으로 구와 다른 묶음이다.

### 이름 규칙

사람이 이름을 붙이지 않는다. 프로필에서 서울 중앙값과 가장 크게 벌어진 두 변수를 골라 자동 설명을 만든다.

```text
평당가 높음 · 도심 7km대
전세가율 높음 · 도심 3km대
```

"고가 강남권", "저가 외곽" 같은 이름은 쓰지 않는다. 가치 판단이 들어간다.

### 알려진 제약

2026Q2 기준 클러스터 크기가 111 / 98 / 4 / 133이다. 크기 4인 클러스터에 속한 동은 함께 볼 동을 낼 수 없다(§6). 그 동들은 구조 유형만 표시하고 비교 블록을 숨긴다.

### 검증

- 최신 기점 소속을 쓰고 "2026Q2 기준, 시장 상황에 따라 바뀔 수 있음" 각주를 단다(결정 65)
- 자동 설명이 프로필 수치와 맞는지 4개 클러스터 전부 수동 확인
- K-δ(δ 경로 클러스터)는 쓰지 않는다. 인접 기점 ARI 0.280으로 소속이 국면마다 바뀐다(결정 58)

## 6. 함께 볼 동

### 목적

관심 동과 구조가 비슷한 동을 함께 보게 한다. 대체 매수처를 고르는 기능이 아니다.

### 방법

같은 K-S 클러스터 안에서 표준화 거리 최근접 5개. 거리 변수는 클러스터를 만든 행렬(`models/index/66`의 `build_matrix`) 8개를 그대로 쓴다. 새 변수를 더하지 않는다.

| 묶음 | feature | 출처 |
|---|---|---|
| 가격 | `log_ppm2` | `dong_feature.sale_ppm2_med_4q`의 log |
| 전세 | `jeonse_ratio` | `dong_feature.jeonse_ratio_4q` |
| 재고·신축 | `log_stock`, `new_share` | `dong_feature.stock_hh`, `completed_hh_8q` |
| 위치 | `lat`, `lng`, `dist_cbd`, `dist_gangnam` | 단지 좌표 중앙, 서울시청·강남역 거리 |

`lat`·`lng`가 들어가면 같은 자치구로 쏠릴 수 있다. 검증에서 쏠림이 확인되면 첫 조정은 두 변수 제외다(`process.md` §2.1 F-4).

### 표시 조건

- 관심 동이 eligible
- 클러스터 크기 10 이상
- 조건을 못 채우면 블록을 숨긴다. "비교할 동이 없습니다"도 쓰지 않는다

### 출력

```json
{
  "peer_dongs": [
    { "dong": "11440_성산동", "reason": "평당가와 전세가율이 가까워요" }
  ]
}
```

`lower_price_alternatives`, `higher_price_alternatives`는 만들지 않는다. 가격대 위아래 후보를 내는 것은 `investment-support-plan.md` §8-1의 미결 결정이다.

### 검증

- 같은 자치구 동만 5개 중 4개 이상 나오는 비율 확인. 높으면 위치 변수 가중을 낮춘다
- 5개 결과가 인접 기점에서 얼마나 유지되는지 확인
- 사유 문구가 실제 거리 기여 상위 변수와 맞는지 수동 20건 점검

## 7. 2차 후보

지금 만들지 않는다. 1차 화면이 §7 성공 기준(`investment-support-plan.md`)을 통과한 뒤 다시 본다.

### 7.1 이벤트 전후 경로

`event_dong_path`의 동 경로와 서울 경로를 같은 그래프에 그린다. 라벨은 만들지 않는다.

막는 것: 저거래 동은 분기 지수 오차가 6%대라 이벤트 반응이 잡음에 묻힌다. 오차 띠를 어떻게 그릴지 정해야 한다. 오차 띠가 경로보다 두꺼우면 그 동은 그래프를 내지 않는다.

### 7.2 leave-one-complex-out 변화율

상위 단지 거래를 빼고 동 지수를 다시 추정해 변화율이 얼마나 달라지는지 본다.

막는 것: hedonic 지수를 동마다 다시 적합해야 한다. 1차에는 `dominant_complex_share_4q` 하나로 같은 질문에 대략 답한다.

### 7.3 면적대 구성 변화

최근 4분기 거래 면적 구성이 직전 4분기와 얼마나 다른지 본다. 구성이 바뀌면 hedonic 보정에도 불구하고 동 평균이 흔들릴 수 있다.

막는 것: 얼마나 달라야 문제인지 기준이 없다. 먼저 분포를 보고 정한다.

## 8. 초안에서 뺀 것

| # | 초안 항목 | 뺀 이유 |
|---|---|---|
| 1 | 데이터 신뢰도 점수 `reliability_grade` A~D, `reliability_score` 0~100 | 등급은 "A등급 동 = 좋은 동"으로 읽힌다. 기존에 "안정형·성장형"을 금지한 이유와 같다. 점수를 만들면 가중치를 정해야 하고 그 가중치를 검증할 방법이 없다. 입력 세 개는 이미 있는 문턱으로 충분히 갈린다 |
| 2 | 현재 국면 분류 `state_label` (거래동반상승, 거래감소상승, 냉각, 회복초기, 저거래불확실) | 최근 4분기 가격 변화와 거래량 변화로 만든 라벨은 결정 55~58이 닫은 모멘텀의 재포장이다. "회복초기"는 미래를 말한다. lag 0 지수를 쓰면 결정 56의 측정오차 문제가 그대로 들어온다. k-means로 라벨 안정성을 비교하자는 초안 계획은 실패한 절차를 한 번 더 돌리는 것이다 |
| 3 | 비슷한 동 "추천", `alternative_dongs` | "추천"은 `front/scripts/check-wording.mjs` 금지어다. "더 낮은 가격대 대체 후보"는 매수 유도로 읽힌다 |
| 4 | 전세 구조 점수 `jeonse_profile` | 초안 출력 예시가 "하방 방어"와 "수요 약화"를 구분하려 했다. 우리 데이터로 두 경우를 구분할 수 없다. 전세가율과 거래량은 사실 정보 블록에 수치로 이미 나간다 |
| 5 | 이벤트 민감도 프로필 `event_sensitivity` (시장민감형, 완만반응형, 정책민감형, 변동성높음) | "~형" 라벨은 금지 구조다. 저거래 동의 분기 오차보다 이벤트 반응이 작아 대부분 잡음이다. 과거 민감도가 앞으로도 같다는 가정은 C-3k가 실행되지 않아 검증되지 않았다 |
| 6 | 거래 왜곡 감지 `distortion_flags` 4개 | "왜곡"은 거래 자체가 잘못됐다는 뜻으로 읽힌다. `TOP_COMPLEX_DRIVES_CHANGE`(LOCO)와 `AREA_MIX_SHIFT`는 2차로 미뤘다(§7). 나머지 둘은 표본 주의 flag에 들어갔다 |
| 7 | "이후 calibration", "k-means 또는 Gaussian mixture" 같은 2단계 계획 | 1단계를 만들기 전에 2단계를 적으면 2단계가 목표가 된다. 1차에 학습하는 모델은 없다 |

## 9. 구현 순서

1. 표본 주의 flag — `output/62.1`과 `dong_index`를 붙이는 집계 스크립트
2. 12개월 변화 표시 — μ 계산과 δ 오차 비교. `models/index/64`의 재고가중 정의 재사용
3. 구조 유형 — `output/66.1` 최신 기점 소속 + `output/66.3` 자동 설명
4. 함께 볼 동 — 3의 소속 안에서 거리 계산

1~2는 기존 실패 결과를 바로 화면 가치로 바꾼다. 3~4는 1~2가 payload에 실린 뒤에 붙인다.

산출 스크립트는 `models/index/69`로 하나만 만든다. 네 산출물이 같은 입력을 읽고 같은 기점 기준을 쓰므로 파일을 나눌 이유가 없다.
