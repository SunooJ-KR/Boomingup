| 5a | 모형: `log(가격/㎡) = 단지×면적bin 고정효과 + 구×분기 효과 + 동×분기 편차`. 면적bin은 3㎡ 폭(임앤장 결정 11). **동×분기 편차에만 ridge 벌점 λ=5**를 걸어 표본이 적은 동을 구 지수 쪽으로 shrinkage한다 | 벌점은 분기마다 걸리므로 동의 편차는 n/(n+λ)만큼 남는다. 동×분기 거래 수 중앙값 9건이면 64%, 최소 표본 기준(결정 7, 연 20건 ≈ 분기 5건)인 동이면 50%가 남는다. λ=20이면 기준선 동이 20%만 남아 구 지수와 거의 같아진다. 결과를 보고 λ를 고르지 않는다 |

| 5c | 반복거래 지수(같은 단지×면적bin의 연속 거래 쌍)는 **점검용으로만** 계산한다. 동별 연간 변화율에 대해 hedonic과의 Spearman 상관을 보고하고, 채택 판단에는 쓰지 않는다 | 구성 편향에 대한 독립 점검 |
| 6 | **target = 기점 분기 t부터 t+h까지 동 지수의 log 변화.** h = 2, 4, 8, 12분기(6·12·24·36개월) | 완결 분기만 쓴다. 데이터가 2026-08에 끝나므로 마지막 완결 분기는 2026Q2다 |

| 8 | **평가 = rolling-origin OOT.** 기점 t의 모델은 s + h ≤ t인 기점 s의 표본만으로 학습한다 (h분기 gap). 평가 기점은 2016Q1부터 (2026Q2 − h)까지 | gap이 없으면 학습 target 기간이 평가 기점 이후와 겹친다. 전월세 feature가 2011년부터라, 2016Q1 이전은 학습 기점을 충분히 쌓기 위한 기간으로 둔다 |

B2: 서울 전체의 직전 h분기 log 변화(기점 t에 결정 7 기준을 통과한 동들의 변화를 동마다 같은 가중치로 평균)를 모든 동에 똑같이 적용한다. 참고로만 보고(채택 판단 제외): B0 변화 0, oracle 서울 미래 평균 | handoff에 적은 "서울 전체 평균 변화율"은 기점 시점에 알 수 없는 미래 값이라, 기점에 계산할 수 있는 형태로 정의했다. oracle은 "시장 전체 흐름을 미리 알아도 동별 차이를 얼마나 맞히는가"를 보는 참고값이다 |

## deviation 기록

사전 등록 규칙(결정 4~13)을 결과 확인 후 바꾸면 여기에 적는다. 한 줄마다 **원래 규칙 · 바꾼 규칙 · 바꾼 이유 · 결과를 본 뒤였는지**를 적는다. 원래 규칙의 결과와 바꾼 규칙의 결과를 발표 자료에 함께 싣는다.
