# 개인 투자자 판단 보조 제품 기획

> 2026-09-17 개정. 첫 초안을 비판적으로 검토해 다시 썼다. 바뀐 점과 이유는 §9에 있다. 같은 날 `seoul-real-estate-investor-sentiment-analysis.md`와 대조해 2차 수정했다. §10.
> 이 문서는 `docs/front/product-plan.md`의 대상·원칙을 바탕으로, 예측이 실패한 뒤 **무엇을 빼고 무엇을 넣는지**를 정한다.

## 1. 출발점이 되는 사실

| 사실 | 근거 |
|---|---|
| 동·구·구조 클러스터·δ 경로 클러스터 어느 단위에서도 과거 상대 변화는 미래 상대 변화를 예측하지 못했다 | 결정 51, 55, 57, 58 |
| 같은 분기 지수를 feature와 target이 공유하면 측정오차가 없는 신호를 만든다. lag 0에서 보이던 순위 신호는 측정오차였다 | 결정 56 |
| 저거래 동의 12개월 변화율 측정오차는 8%대다. eligible 동은 약 2.5% | 결정 42 (SE 0.0585·0.0176 × √2) |
| 화면 헤드라인은 δ도 nowcast도 낼 수 없다. 남는 것은 데이터 신뢰도 블록, 시장 구조 정보, μ 참고치다 | 결정 53 |
| 클러스터 소속은 예측이 아니라 관측이므로 사실 정보로 쓸 수 있다. 단 K-S(구조 변수)만 안정적이다(인접 기점 ARI 0.90). K-δ는 0.28로 국면마다 바뀐다 | 결정 57, 58 |

이 사실에서 바로 따라오는 제품 규칙 두 가지:

1. **과거 변화율을 라벨로 바꾸지 않는다.** "상승", "냉각", "회복" 같은 이름은 그 상태가 이어진다는 뜻으로 읽힌다. 우리 데이터는 그 뜻을 뒷받침하지 못한다.
2. **변화율은 측정오차와 함께만 보여 준다.** 오차보다 작은 변화는 "서울 평균과 구분되지 않음"으로 쓴다.

## 2. 사용자 문제 — 가설과 검증

첫 초안은 사용자 문제를 사실처럼 적었다. 실제로는 **모델 팀이 겪은 문제**(측정오차, 단지 쏠림)를 사용자 문제로 옮겨 적은 것이다. 사용자 조사는 없었다. 그래서 가설로 낮추고 검증 방법을 붙인다.

| 가설 | 우리가 보여줄 수 있는 것 | 검증 방법 |
|---|---|---|
| H1. 사용자는 거래가 적은 동의 변화율을 거래가 많은 동과 같은 무게로 읽는다 | 거래 건수, 거래 단지 수, 추정오차 구간 | 숫자만 준 그룹과 주의 표시를 준 그룹의 해석 차이를 5명 내외 인터뷰로 본다 |
| H2. 동 평균 변화가 특정 단지 거래 때문인지 알고 싶어 한다 | 상위 단지 거래 비중, 거래 단지 수 | 같은 인터뷰. "이 변화율을 믿겠는가"를 묻고 근거로 무엇을 보는지 기록한다 |
| H3. 관심 동과 구조가 비슷한 동을 함께 보고 싶어 한다 | K-S 클러스터 소속과 그 안의 최근접 동 | 비교 블록을 열었을 때 실제로 다른 동을 클릭하는지 본다 |
| H4. 전세가율과 정비사업 같은 사실 정보를 한 화면에서 보고 싶어 한다 | 이미 있는 사실 정보 | 기존 화면 유지. 별도 검증 안 함 |

**가장 큰 위험은 제품·시장 적합성이다.** 사용자가 원하는 것은 여전히 "어디가 오르나"일 수 있다. 그 답을 주지 않는 제품이 쓰일지는 위 인터뷰 전에는 모른다. 1차 버전의 목적은 기능 완성이 아니라 이 위험을 확인하는 것이다.

### 2.1 투자자 심리 2차 자료와의 대조

`seoul-real-estate-investor-sentiment-analysis.md`는 심리지수, 설문, 한국은행·국토연구원 자료를 웹에서 모아 요약한 2차 자료다. 우리 사용자 조사가 아니고, 인용된 설문 일부는 서울 투자자만을 대상으로 한 것이 아니다. 그래서 H1~H4를 대체하지 않는다. 다만 위험을 더 구체적으로 만든다.

자료가 정리한 "투자자가 알고 싶은 것 다섯 가지"에 우리 제품을 대조하면 이렇다.

| 투자자 질문 | 우리 답 | 이유 |
|---|---|---|
| ① 오를까 | 없음 | 결정 51·55·57·58. 동별 상대 예측이 기준선을 못 이겼다 |
| ② 지금 사도 될까 (고점인가 저평가인가) | 없음. 관측만 제공 | "저평가"는 금지어. 5년 지수 범위 안 현재 위치는 사실로 낸다(§4.1 블록 2). 그것이 고점인지는 말하지 않는다 |
| ③ 같은 예산으로 어디가 나은가 | 부분. 가격대 필터와 함께 볼 동 | 비교는 하게 하되 우열은 말하지 않는다 |
| ④ 떨어져도 버틸까 | 부분. 전세가율, 거래량, 표본 상태 | 대출·보유비용은 사용자 사정이라 우리 데이터에 없다. 입주 예정 물량도 없다(`docs/data-and-schema.md` §6) |
| ⑤ 나중에 누가 사줄까 | 없음 | 매수자 연령·거주지 데이터가 없다. 있어도 미래 수요 추정은 예측이다 |

다섯 중 셋에 답이 없다. 이것이 제품·시장 적합성 위험의 실제 크기다. 자료가 서비스 방향으로 제시한 "덜 오른 곳은 어디인가", "현재 어떤 유형의 투자자에게 적합한가"는 각각 "저평가"와 "투자 적격"의 다른 표현이라 채택하지 않는다.

자료에서 채택한 것 세 가지:

- **가격대가 탐색 입구다.** 투자자는 예산으로 시작한다. 목록 필터에 가격대를 넣는다(§4.2). 가격은 사실이고 판단이 아니다.
- **투자자는 "잘못 산 것은 아니다"라는 근거를 원한다.** 자료의 ⑦ 하락 위험 회피 심리는 실거래·전고점·거래량·전세가를 반복 확인하는 행동으로 나타난다. 이 확인 행위에 측정오차와 표본 상태를 붙이는 것이 우리 제품이 실제로 하는 일이다. 5년 범위 내 위치를 사실 블록에 추가한다(§4.1).
- **인터뷰 표본을 유형별로 나눈다.** 자료가 제안한 유형 중 우리 데이터로 검증 가능한 넷을 쓴다. 첫 집(30대), 갈아타기, 상급지 이동, 정비사업 관심. 5명이 한 유형에 몰리면 H1~H4 결과가 그 유형의 답이 된다. 현금흐름 투자자는 월세 수익률이 필요한데 우리 화면에 없으므로 뺀다.

자료에서 채택하지 않은 것: 기대심리가 가격에 선행한다는 한국은행 연구는 서울 전체 수준의 이야기다. 동별 상대 예측이 안 된다는 우리 결과와 충돌하지 않고, 예측을 다시 열 근거도 아니다.

대상, 제공 가치, 제공하지 않는 것은 `docs/front/product-plan.md` §1을 그대로 따른다. 여기서는 바뀌는 점만 적는다.

| 7 | 이벤트 전후 흐름 | 이벤트 기준일 전후 동·서울 지수 경로 | `event_dong_path`, `event_summary` | 2차. §6 |

표본 주의 flag는 다음 세 개만 둔다. 등급(A~D)은 만들지 않는다(§9-3).

|---|---|---|

### 4.2 목록과 필터

| 필터 | 내용 | 비고 |
|---|---|---|
| 자치구 | 기존 | |

정렬은 이름, 자치구, 매매 건수, ㎡당 중앙가만 제공한다. **변화율 정렬은 제공하지 않는다.** 정렬 가능한 변화율은 순위이고, 순위는 "많이 오른 동"으로 읽힌다. 가격 정렬은 사실의 순서라 허용한다. 단 "가성비", "저렴한 순" 같은 이름을 붙이지 않는다.

### 4.3 지도

색은 표본 상태(주의 flag 유무)와 구조 유형만 쓴다. 변화율로 색칠하지 않는다. 목록과 지도에서 변화율 순위를 만들지 않는 결정 67을 따른다.

## 5. 표현 규칙

`front/scripts/check-wording.mjs`의 금지 목록에 더해 이 제품에서 새로 금지하는 표현:

| 금지 | 이유 | 대신 쓰는 표현 |
|---|---|---|
| 추천, 대체 후보, 대안 | 이미 금지어인 "추천"과 같은 뜻. "더 싼 대안"은 매수 유도로 읽힌다 | 함께 볼 동, 구조가 비슷한 동 |
| 국면, 상승 국면, 냉각, 회복 | 과거 변화율에 이름을 붙여 지속을 암시한다 | 지난 12개월 변화 +x%(오차 ±y%) |
| ~형 (시장민감형, 완만반응형) | 기존에 금지한 "안정형·성장형"과 같은 구조 | 이벤트 전후 변화 수치 |
| 왜곡 | 거래 자체가 잘못됐다는 뜻으로 읽힌다 | 쏠림, 한 단지 비중 |
| 하방 방어, 수요 약화 | 전세가율을 원인으로 해석한다. 데이터로 구분할 수 없다 | 전세가율 x%, 지난해 대비 ±y%p |
| 실적 | 수익률로 읽힌다 | 매매 가격 분포 |
| 신뢰도 A/B/C/D | 동의 등급으로 읽힌다 | 표본 주의 flag |
| 고점, 저점, 바닥, 꼭지, 회복률, 전고점 회복 | 5년 범위 위치를 매수 시점 판단으로 바꾼다 | 5년 최고 대비 −x%(오차 ±y%) |
| 다음 오를 곳, 확산, 갭 메우기, 키 맞추기 | 상승이 인접 지역으로 번진다는 예측이다. 우리 데이터로 검증되지 않았다 | 쓰지 않는다 |
| 갈아타기, 상급지, 하급지 | 동 사이에 등급을 매긴다 | 가격대가 높은 동 / 낮은 동 (수치와 함께) |
| 적합한 투자자, 투자 유형, 성향 진단 | "투자 적격"의 다른 표현 | 쓰지 않는다 |
| 가성비, 저렴한 순, 예산으로 살 수 있는 | 가격 필터를 추천으로 바꾼다 | ㎡당 중앙가 x~y만원 |

클러스터 이름 규칙: 사람이 이름을 붙이지 않는다. `output/66.3`의 프로필 상위 두 값으로 자동 설명한다. 예: "평당가 높음 · 도심 거리 7km대". "고가 강남권", "저가 외곽" 같은 이름은 가치 판단이 들어가므로 쓰지 않는다.

쓸 수 있는 문장 예:

```text
최근 1년 매매 38건, 거래 단지 9개. 지수 추정오차는 낮은 편이에요.
지난 12개월 변화는 서울 평균과 구분되지 않아요(차이 +1.2%, 오차 ±2.5%).
최근 거래의 절반 이상이 한 단지에서 나왔어요. 동 전체 흐름으로 읽기엔 표본이 좁아요.
같은 구조 유형에서 가격대와 전세가율이 가까운 동이에요.
```

## 6. MVP 범위

| 1차 | 2차 | 하지 않음 |
|---|---|---|
| 표본 주의 flag 3개 | 이벤트 전후 흐름 그래프 | 동별 변화율 순위·정렬 |
| δ 오차 병기 표시 | flag별 세부 필터 | 국면 라벨 |
| 5년 최고 대비 위치(오차 병기) | leave-one-complex-out 변화율 | 이벤트 민감도 라벨 |
| 구조 유형 태그(K-S, 자동 설명) | 면적대 구성 변화 flag | 전세 구조 "해석" |
| 함께 볼 동 5개 | | 매수·매도·대안 표현 |
| 가격대 필터·정렬 | | 정책 문턱 수동 입력 전 K-4 |
| 기존 사실 정보 유지 | | 고점·저평가 판정, 다음 오를 곳 |
| μ 참고치 접힘 | | 투자자 유형별 적합도 |
| | | 매수자 연령·입주 예정 물량 (데이터 없음) |

2차로 미룬 이유:

- **이벤트 전후 흐름**: 데이터는 있다(`event_dong_path`). 그러나 저거래 동은 분기 오차 6%로 이벤트 반응이 잡음에 묻힌다. 서울 경로와 동 경로를 오차 띠와 함께 그리는 방식이 정해진 뒤 넣는다. 라벨은 만들지 않는다.
- **leave-one-complex-out**: hedonic 지수를 동마다 다시 추정해야 한다. `dominant_complex_share_4q`가 같은 질문에 대략 답하므로 1차에는 비중만 쓴다.

하지 않는 이유는 §1과 §9에 있다.

## 7. 1차 버전 성공 기준

모델 성능이 아니라 **읽히는 방식**으로 판단한다.

| 기준 | 측정 | 통과 |
|---|---|---|
| 판단 표현으로 읽히지 않음 | 인터뷰 5명에게 상세 화면을 보여 주고 "이 화면이 사라고 하는가"를 묻는다 | 5명 중 4명 이상이 "아니다" |
| 주의 flag가 해석을 바꿈 | 같은 동을 flag 없이 / 있게 보여 주고 변화율을 얼마나 믿는지 묻는다 | flag가 있을 때 신뢰가 낮아짐 |
| 함께 볼 동이 쓰임 | 비교 블록에서 다른 동 클릭 비율 | 인터뷰 중 절반 이상이 클릭 |
| 금지 표현 없음 | `npm run check:wording` + §5 추가 목록 | 0건 |

통과하지 못하면 화면을 더 만들지 않고 §2 가설로 돌아간다.

## 8. 결정이 필요한 것

`process.md` §6의 다섯 질문 중 셋은 이미 답이 있다.

| 질문 | 답 | 근거 |
|---|---|---|
| μ 참고치를 남길 것인가 | 남긴다. 접힘, "예측 아님" 표기 | 결정 53 |
| 신뢰도 등급 A~D인가 3단계인가 | 둘 다 아니다. 주의 flag 3개 | §9-3 |
| 클러스터 이름을 사람이 붙일 것인가 | 아니다. 프로필 상위값으로 자동 설명 | §5 |

남는 결정:

1. **함께 볼 동을 같은 가격대 안에서만 고를 것인가.** 가격대 위아래를 함께 보여 주면 "더 싼 곳"으로 읽힌다. 1차는 같은 클러스터 안 최근접만 제안한다. 심리 자료(§2.1)는 상급지 이동이 주된 동기라고 하므로 가격대 위 후보에는 실제 쓸모가 있을 수 있다. 반대로 가격대 아래 후보는 "덜 오른 곳" 탐색과 겹쳐 더 위험하다. 2차에서 위쪽만 넣는 안을 검토한다.
2. **`status` 컬럼과 `dong_prediction` 테이블을 어떻게 정리할 것인가.** 결정 66과 `docs/payload-schema.md` §3·§8에서 `sample_flags` 전환과 테이블 유지 방식을 정했다.
3. **인터뷰를 누가 언제 하는가.** §2·§7의 검증은 사람과 일정이 있어야 한다.
