- 조치가 하나이고 효력일이 명확하면 **효력일**을 기준일로 쓴다 (규제지역 지정·해제, 대출 한도 시행 등)

## 5. 겹치는 이벤트 (분리해서 해석할 수 없음)

이벤트 분기 차이가 4분기 이내면 어느 이벤트의 흐름인지 가를 수 없다. 화면에서는 겹친 이벤트를 반드시 함께 표시한다.

| 묶음 | 이벤트 |
|---|---|
| 2006~2007 | P16 · P17 · P18 |
| 2008~2009 | G1 · M1 · R1 · P19 · R2 |
| 2010 | R3 · P20 |
| 2011~2012 | P21 · P22 · R4 |
| 2014~2016 | P1 · P23 (P23 시행은 P1 후 6분기라 경계) |
| 2016~2017 | P2 · G3 · P3 · P4 · R5 |
| 2018 | P24 · P5 |
| 2019~2021 | R6 · P6 · M2 · M3 · R7 · P7 · P8 · P9 · P10 · R8 |
| 2022~2023 | G4 · P25 · P26 · P11 · R9 |
| 2024~2025 | P27 · P12 · P28 · R10 · P29 · P30 · G5 · P13 · P14 · P15 |

- P29(해제)와 P30(지정)은 약 한 달 간격의 **반대 방향** 이벤트다. 같은 분기(2025Q1)라 결과가 같게 나오므로 반드시 함께 보여 준다
- 같은 분기 이벤트(R9·P11, G5·P13, P14·P15, M2·M3·R7 등)는 계산 결과가 똑같다

## 6. 보여 줄 방식

- 이벤트 기준 분기(이벤트 분기 − 1)를 0으로 맞춰 전 4분기 ~ 후 4분기 동별 지수 경로를 보여 준다 (`models/index/46.event_study.py`)
- "이 동 +X%, 서울 평균 +Y%, 같은 방향으로 움직인 동 N개/전체"처럼 사실만 적고, 겹친 이벤트를 함께 표시한다
- 금지: "규제 때문에 떨어졌다", "금리 인하 후 오를 것이다" 같은 인과·예측 표현
