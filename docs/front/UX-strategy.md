## [UX Writing Tone]

모든 사용자 노출 문구는 **토스 스타일의 Conversational UX Writing**을 따른다.

* 어렵고 공식적인 표현보다 **쉽고 자연스러운 일상 언어**를 사용한다.
* `~합니다`, `~되었습니다` 같은 딱딱한 문어체보다 **`~해요`, `~됐어요` 형태의 부드러운 존댓말**을 우선한다.
* 문장은 가능한 한 **짧고 명확하게** 작성한다.
* 사용자가 지금 알아야 할 **핵심 정보와 다음 행동을 먼저** 전달한다.
* 전문용어, 행정적 표현, 중복 표현, 불필요한 수식어를 최소화한다.
* 시스템 관점보다 **사용자 관점에서 상황을 설명**한다.
* 오류나 경고 문구에서는 문제만 알리지 말고 **사용자가 다음에 무엇을 해야 하는지 함께 안내**한다.
* 지나치게 친근하거나 장난스러운 표현은 피하고, **친근하지만 신뢰감 있는 서비스 톤**을 유지한다.

### Examples

**Before**

* 회원가입이 정상적으로 완료되었습니다.
* 해당 데이터를 조회할 수 없습니다.
* 로그인이 필요합니다.

**After**

* 가입이 완료됐어요.
* 데이터를 불러오지 못했어요. 다시 시도해주세요.
* 계속하려면 로그인해주세요.

**Button**

* `확인을 진행합니다` → `확인하기`
* `분석을 실행합니다` → `분석하기`
* `이전 페이지로 이동` → `이전으로`
