# Boomingup 대표 이미지 슬라이드 초안

## 1. 슬라이드 목적

- 용도: AI 해커톤 제출용 프로젝트 대표 이미지
- 화면 비율: 16:9 와이드 PowerPoint 슬라이드 1장
- 대상: 서비스와 기술을 처음 접하는 심사위원
- 전달할 한 문장: Boomingup은 AI로 서울의 동네를 비슷한 조건끼리 연결하고, 데이터의 불확실성까지 함께 보여 줘요.

## 2. 핵심 콘셉트

### 메인 카피

**서울의 동네, 같은 기준으로 비교해요**

### 보조 카피

346개 법정동의 가격·주택·입지 데이터를 AI로 분석해  
비슷한 지역과 데이터의 신뢰 수준을 함께 보여 줘요.

### 하단 메시지

지난 거래를 바탕으로 비교 정보를 제공하며, 매수·매도 판단을 대신하지 않아요.

## 4. 영역별 문구

### 좌측 지도 영역

- 지도 상단: `서울 346개 법정동을 살펴봐요`
- 선택 지역 라벨: `{자치구} {법정동}`
- 지도 각주: `색은 표본 상태와 클러스터 구분이에요. 변화율이 아니에요.`

지도에는 서울 전체 윤곽과 자치구 경계를 표시하고, 선택한 동 하나를 분명하게 강조한다. 여러 색은 지역의 우열이 아니라 군집 구분에만 사용한다.

### 중앙 연결 영역

세 단계가 왼쪽에서 오른쪽으로 이어지게 표시한다.

1. `가격·주택·입지 데이터`
2. `AI 군집화·유사도 탐색`
3. `비교 정보와 신뢰 수준`

아이콘은 데이터베이스, 연결된 점, 비교 화살표처럼 의미가 바로 보이는 형태를 사용한다. 복잡한 모델 구조도나 수식은 대표 이미지에 넣지 않는다.

### 우측 서비스 화면 영역

실제 상세 화면을 크게 배치하고 다음 정보가 읽히게 한다.

- `표본 상태`
- `아파트 가격 지수는 얼마나 달라졌을까요?`
- `클러스터 성질`
- `함께 볼 동`
- `데이터 모델링 · 군집화`
- `데이터 모델링 · 유사도 탐색`

화면 예시 문구는 아래처럼 짧게 구성한다.

> 최근 거래의 절반 이상이 한 단지에서 나왔어요  
> 서울 평균과 구분되지 않아요  
> 평당가와 도심 거리가 가까워요

### 핵심 수치 영역

수치는 카드처럼 분리하지 않고 지도 아래 한 줄에 간결하게 배치한다.

| 수치 | 설명 |
|---|---|
| `346개` | 서울 법정동 |
| `8가지` | 가격·주택·입지 변수 |
| `4개` | 비슷한 특성으로 묶은 클러스터 |
| `5곳` | 선택한 동과 함께 볼 동 |

## 5. 시각 방향

- 실제 제품 화면과 서울 지도를 대표 시각 요소로 사용한다.
- 배경은 밝은 무채색으로 두고, 브랜드 색은 제목과 선택 지역 강조에 제한한다.
- 클러스터 색은 서로 구분되지만 어느 색도 더 좋아 보이지 않도록 채도와 밝기를 비슷하게 맞춘다.
- 숫자보다 선택한 동과 함께 볼 동 사이의 연결 관계가 먼저 보이게 한다.
- 둥근 카드가 반복되는 대시보드 형태보다 하나의 지도와 하나의 제품 화면이 이어지는 구성을 사용한다.
- 메인 제목은 50~56pt, 보조 카피는 22~26pt, 화면 설명은 16~18pt를 기준으로 한다.

## 6. UX Writing 적용 기준

- 쉽고 차분한 `~해요`체를 사용한다.
- AI가 답을 정하거나 지역을 권하는 것처럼 표현하지 않는다.
- 지나간 거래의 관측값과 앞으로의 가격 방향을 구분한다.
- 수치에는 오차 또는 표본 상태를 함께 보여 준다.
- 지역의 우열이나 투자 가치를 암시하는 표현을 쓰지 않는다.
- 전문 용어는 필요한 곳에만 쓰고, 사용자에게 보이는 문장에는 뜻을 함께 설명한다.

사용하지 않는 표현:

`추천`, `유망`, `저평가`, `고평가`, `적정가`, `투자 적격`, `예측`, `전망`, `매수 타이밍`
