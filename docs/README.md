# 개인 투자자 판단 보조 문서 안내

> 작성: 2026-09-17. 기존 동별 상승률 예측 실험의 실패 결론을 반영해, 현재 보유 데이터로 만들 수 있는 머신러닝 제품 방향을 다시 정의한다.

## 1. 배경

기존 모델 개발은 서울 법정동별 12개월 상승률을 직접 예측하는 방향이었다. 그러나 최신 평가에서 동별 상대 변화, nowcast, 구 단위 모멘텀, 구조 클러스터 모멘텀, δ 경로 클러스터가 모두 기준선을 유의하게 이기지 못했다.

따라서 새 기획은 "어느 동이 더 오를지 맞히는 모델"이 아니라, 개인 투자자가 지역을 비교할 때 필요한 **표본 상태, 측정오차와 함께 읽는 관측 변화, 구조 유형, 비교군, 사실 정보**를 보여 주는 제품으로 전환한다.

전환의 핵심 규칙 두 가지다. **과거 변화율에 라벨을 붙이지 않는다.** 라벨은 그 상태가 이어진다는 뜻으로 읽히는데, 위 결과가 그 뜻을 부정했다. **변화율은 측정오차와 함께만 낸다.** 오차보다 작은 차이는 수치로 내지 않는다.

## 2. 기존 문서에서 가져온 전제

| 출처 | 가져올 내용 |

| `docs/data-and-schema.md` | 사용할 수 있는 데이터 범위, `dong_index`, `dong_feature`, `trade_sale`, `trade_rent`, `complex`, `event_summary`, `event_dong_path` |

## 3. 새 제품 원칙

| 원칙 | 의미 |
|---|---|
| 예측보다 판단 보조 | 수익률을 찍지 않고, 사용자가 숫자를 해석할 때 필요한 맥락을 제공한다 |
| 좋고 나쁨 대신 관측 특징 | "유망", "저평가" 대신 "거래 집중 높음", "전세가율 높음", "지수 오차 큼"처럼 쓴다 |
| 모델 출력마다 근거 표시 | 점수만 보여 주지 않고, 어떤 feature 때문에 그런 결과가 나왔는지 함께 보여 준다 |
| 불확실성 먼저 노출 | 거래가 적거나 특정 단지에 쏠린 값은 결과보다 주의 문구를 먼저 보여 준다 |
| 새 외부 데이터 의존 최소화 | 1차 버전은 현재 DB와 산출물로 만들 수 있는 모델만 포함한다 |

## 4. 1차 산출물 묶음

우선순위는 다음 네 가지다. 정의와 검증 기준은 `model-candidates.md`에 있다.

| 순서 | 산출물 | 사용자 질문 | 1차 출력 |
|---|---|---|---|
| 1 | 표본 주의 flag | 이 동의 숫자를 얼마나 조심해서 읽어야 하는가 | 매매 부족, 한 단지 쏠림, 지수 오차 큼 세 가지 |
| 2 | 12개월 변화 표시 | 이 동은 서울 평균과 다르게 움직였는가 | 변화율과 오차. 오차보다 작으면 "구분되지 않음" |
| 3 | 구조 유형 | 이 동은 어떤 특성의 동네인가 | K-S 클러스터 소속과 프로필 자동 설명 |
| 4 | 함께 볼 동 | 이 동과 같이 볼 만한 동은 어디인가 | 같은 클러스터 안 최근접 5개 |

넷 다 학습하는 모델이 아니라 이미 있는 값의 집계와 문턱 판정이다.

이벤트 전후 경로와 leave-one-complex-out 변화율은 2차 후보다. 전세 구조 점수와 이벤트 민감도 프로필은 산출물에서 뺐다. 전세가율과 거래량은 사실 정보로 이미 화면에 나가고, 그것을 "하방 방어"나 "시장민감형" 같은 해석으로 바꾸면 투자 조언으로 읽힌다.

## 6. 하지 않는 것

- 동별 12개월 상승률 순위 제공, 변화율 정렬, 변화율 지도 색칠
- 매수·매도·보유 추천
- 저평가, 고평가, 유망, 투자 적격 같은 판단 문구
- 특정 단지 적정가 판정
- **과거 변화율에 붙이는 라벨.** 국면 이름(상승·냉각·회복), 등급(A~D), 유형 이름(시장민감형·안정형)
- **사실을 원인으로 바꾸는 해석.** 전세가율이 하방 방어인지 수요 약화인지 같은 문장
- 외부 고시 원문 확인이 필요한 정책 문턱 feature를 원문 없이 임의 입력
